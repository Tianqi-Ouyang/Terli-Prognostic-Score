Xing — Prognostic Score Analysis

Published

April 14, 2026

Notes on Original Code

Question Answer
Is Xing new.Rmd the newest version, and Code.Rmd the older one? Yes. Xing new.Rmd was last modified Jan 28, 2025; Code.Rmd was last modified Jan 26, 2025. Current Table 1 and RPubs results were generated from Xing new.Rmd.
Why do the Cox / timeROC / logistic regression sections reference clif_c_score_new instead of the day-0 clif_c_score_day0? clif_c_score_new is not defined in Xing new.Rmd — it comes from the parent shared pipeline (it’s clif_c_score with NAs median-imputed, using a single MAP reading rather than the median of 4). The original script silently used the pipeline’s version instead of the locally-computed clif_c_score_day0. Fixed in this analysis: all models now reference clif_c_score_day0 (see row 3 of the Error table below).
Is the commented-out MELD median imputation block (lines 297-319) intentional? Yes, intentionally disabled. That block was a fallback-then-median strategy: replace missing day-0 labs with admission labs (scr_terli_day0 ← admit_creatinine_adj, etc.), then median-impute the remainder, then also median-impute the resulting MELD scores themselves. In the current analysis, day-0 labs used for MELD (bili_terli_day0, scr_terli_day0, inr_terli_day0, alb_terli_day0) ARE median-imputed before score calculation, but na_terli_day0 is not in the imputation list — patients missing day-0 sodium will have NA MELD-Na and MELD 3.0. This matches the original script’s behavior.

Error Fixed Applied

Error Solution
day0_meld / day0_meld_3 use raw scr_terli_day0 instead of capping to [1, 4] — MELD specification requires creatinine capped before calculation. The shared pipeline does this; the original code overwrites with uncapped versions. Added creatinine_adj_day0 = case_when(scr_terli_day0 < 1 ~ 1, scr_terli_day0 >= 4 ~ 4, TRUE ~ scr_terli_day0) and used it in day0_meld and day0_meld_3 formulas
dc_meld / dc_meld_3 also use raw dc_scr without capping to [1, 4] — same MELD capping rule applies to discharge scores Added dc_creatinine_adj = case_when(dc_scr < 1 ~ 1, dc_scr >= 4 ~ 4, TRUE ~ dc_scr) and used it in dc_meld and dc_meld_3 formulas
clif_c_score_day0 computed but never used — all models referenced clif_c_score_new (from shared pipeline, uses single MAP reading) instead of clif_c_score_day0 (uses median of 4 MAP readings) Replaced clif_c_score_new with clif_c_score_day0 in all Cox, timeROC, and logistic regression models
albvolume_before_terli in num_vars but not in all_vars — silently excluded from Table 1 Added albvolume_before_terli to all_vars

CLIF-C Score Function

Show CLIF-C function 
calculate_clif_c_score <- function(tb_admit, peak_creatinine, he_grade_admission, inr_admit, map, pressor, fio2_admission, spo2_admission, age_admission, wbc_admit) {

  clif_score <- 0

  # TB Admit Score
  clif_score <- clif_score + case_when(
    is.na(tb_admit) ~ 0,
    tb_admit < 6 ~ 1,
    tb_admit >= 6 & tb_admit < 12 ~ 2,
    tb_admit >= 12 ~ 3,
    TRUE ~ 0
  )

  # Peak Creatinine Score
  clif_score <- clif_score + case_when(
    is.na(peak_creatinine) ~ 0,
    peak_creatinine < 2 ~ 1,
    peak_creatinine >= 2 & peak_creatinine < 3.5 ~ 2,
    peak_creatinine >= 3.5 ~ 3,
    TRUE ~ 0
  )

  # HE Grade Admission Score
  clif_score <- clif_score + case_when(
    is.na(he_grade_admission) ~ 0,
    he_grade_admission == 1 ~ 1,
    he_grade_admission %in% c(2, 3) ~ 2,
    he_grade_admission %in% c(4, 5) ~ 3,
    TRUE ~ 0
  )

  # INR Admit Score
  clif_score <- clif_score + case_when(
    is.na(inr_admit) ~ 0,
    inr_admit < 2 ~ 1,
    inr_admit >= 2 & inr_admit < 2.5 ~ 2,
    inr_admit >= 2.5 ~ 3,
    TRUE ~ 0
  )

  # MAP and Pressor Score
  clif_score <- clif_score + case_when(
    is.na(map) ~ 0,
    map >= 70 & pressor != 1 ~ 1,
    map < 70 & pressor != 1 ~ 2,
    !is.na(map) & pressor == 1 ~ 3,
    TRUE ~ 0
  )

  # FIO2 and SPO2 Admission Score
  if (!is.na(fio2_admission)) {
    ratio <- spo2_admission / fio2_admission
    clif_score <- clif_score + case_when(
      ratio > 357 ~ 1,
      ratio > 214 & ratio <= 357 ~ 2,
      ratio <= 214 ~ 3,
      TRUE ~ 0
    )
  }

  # Calculate CLIF-C Score
  CLIF_C_Score <- 10 * (0.33 * clif_score + 0.04 * age_admission + 0.63 * log(wbc_admit) - 2)

  return(CLIF_C_Score)
}

    death_status_check = case_when(

      TRUE ~ 0
    ),

    time_to_death_check = case_when(
      disposition == 5                                                     ~ days_to_dc_init,
      dc_death_90days == 2                                                 ~ days_to_los_init,
      dc_death_90days == 1                                                 ~ days_to_after_dc_death_init,
      dc_death_90days == 0 & is.na(days_to_lastencounter_init)             ~ days_to_los_init,
      dc_death_90days == 0 & !is.na(days_to_lastencounter_init)            ~ days_to_lastencounter_init,
      TRUE ~ NA_real_
    ),
    death_status_90days_init = ifelse(time_to_death_check <= 90 & death_status_check == 1, 1, 0),
    time_to_death_90days_init = ifelse(time_to_death_check <= 90, time_to_death_check, 90)
  )

master <- master %>%
  mutate(

    dc_tbili   = ifelse(is.na(dc_tbili),   median(dc_tbili,   na.rm = TRUE), dc_tbili),
    dc_inr     = ifelse(is.na(dc_inr),     median(dc_inr,     na.rm = TRUE), dc_inr),
    dc_sna     = ifelse(is.na(dc_sna),     median(dc_sna,     na.rm = TRUE), dc_sna),
    dc_albumin = ifelse(is.na(dc_albumin), median(dc_albumin, na.rm = TRUE), dc_albumin)
  )

# --- Discharge MELD scores ---
master <- master %>%
  mutate(
    dc_creatinine_adj = case_when(dc_scr < 1 ~ 1, dc_scr >= 4 ~ 4, TRUE ~ dc_scr),
    dc_meld = round(9.57 * log(dc_creatinine_adj) + 3.78 * log(dc_tbili) + 11.20 * log(dc_inr) + 6.43),
    dc_meld_na = round(dc_meld + 1.32 * (137 - pmin(pmax(dc_sna, 125), 137)) -
                         (0.033 * dc_meld * (137 - pmin(pmax(dc_sna, 125), 137)))),
    dc_meld_na = ifelse(dc_meld_na > 11, dc_meld_na, NA),
    sex_male = as.numeric(sex_male),
    female_factor = if_else(sex_male == 0, 1.33, 0),
    dc_meld_3 = round(
      female_factor +
        4.56 * log(dc_tbili) +
        0.82 * (137 - dc_sna) -
        0.24 * (137 - dc_sna) * log(dc_tbili) +
        9.09 * log(dc_inr) +
        11.14 * log(dc_creatinine_adj) +
        1.85 * (3.5 - dc_albumin) -
        1.83 * (3.5 - dc_albumin) * log(dc_creatinine_adj) +
        6
    )
  )

# --- Day-0 MELD scores (recalculated from day-0 labs) ---
master <- master %>%
  mutate(
    creatinine_adj_day0 = case_when(scr_terli_day0 < 1 ~ 1, scr_terli_day0 >= 4 ~ 4, TRUE ~ scr_terli_day0),
    day0_meld = round(9.57 * log(creatinine_adj_day0) + 3.78 * log(bili_terli_day0) + 11.20 * log(inr_terli_day0) + 6.43),
    day0_meld_na = round(day0_meld + 1.32 * (137 - pmin(pmax(na_terli_day0, 125), 137)) -
                           (0.033 * day0_meld * (137 - pmin(pmax(na_terli_day0, 125), 137)))),
    day0_meld_na = ifelse(day0_meld_na > 11, day0_meld_na, NA),
    sex_male = as.numeric(sex_male),
    female_factor = if_else(sex_male == 0, 1.33, 0),
    day0_meld_3 = round(
      female_factor +
        4.56 * log(bili_terli_day0) +
        0.82 * (137 - na_terli_day0) -
        0.24 * (137 - na_terli_day0) * log(bili_terli_day0) +
        9.09 * log(inr_terli_day0) +
        11.14 * log(creatinine_adj_day0) +
        1.85 * (3.5 - alb_terli_day0) -
        1.83 * (3.5 - alb_terli_day0) * log(creatinine_adj_day0) +
